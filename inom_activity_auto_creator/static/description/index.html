Smart Activity Auto Creator

Automate your follow-ups effortlessly in Odoo. This module automatically creates activities based on key business actions like Sales Orders and Invoices — ensuring no task is ever missed.

✨ Key Features

Sales Order Automation

Automatically creates activities when a Sales Order is confirmed.

Invoice Triggered Activities

Instantly generate follow-up tasks after invoice posting.

Fully Configurable

Customize activity type, responsible user, deadline, and notes.

⚙️ How It Works

Step 1: Sales Order Confirmation

When a Sales Order is confirmed, an activity is automatically created.

Step 2: Invoice Posting

Posting an invoice triggers automatic activity creation for follow-up.
