Audit Trail for Odoo

Know who changed what, when — and from where. Rule-based activity logging, field-level change history and a live audit dashboard for Odoo 17, 18 & 19.

Audit Trail is the complete audit log / user activity tracking app for Odoo. Track Create, Read, Update and Delete on any object, record the exact old value → new value for every tracked field, and capture the user's IP address and browser. Perfect for compliance, data security and accountability.

Key Features

  • Rule-based tracking per object (model) — choose exactly which Odoo objects to audit.
  • Track Create / Read / Update / Delete — turn each operation on or off per rule.
  • Field-level change history — record the old value and new value of the fields you pick.
  • Who changed what — every entry stores the user, date/time and the affected record.
  • IP address & browser tracking — plus optional GeoIP location.
  • Group restriction — log only actions performed by specific user groups.
  • Live audit dashboard — active users now, activity today vs yesterday, active rules.
  • Works with any custom module — no per-model development required.
