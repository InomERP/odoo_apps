Key Features

  • Default CC / BCC: Set default CC and BCC emails for every outgoing email, saving time and avoiding mistakes.
  • Reply-To Control: Customize Reply-To addresses easily, ensuring responses go to the correct inbox.
  • Email Tracking: Track sent emails with automatic logging, giving better insights on communication.

How It Works

  1. Install the module in your Odoo environment.
  2. Configure default CC, BCC, and Reply-To addresses in the settings.
  3. Send emails from any Odoo model, and the defaults will automatically apply.
  4. Track all sent emails in the chatter or log for full transparency.
  5. This feature works globally across all Odoo applications, automatically integrating with any module where the "Send Email" button is available, ensuring consistent email management throughout your system.
