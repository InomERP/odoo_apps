# Inom POS Stock Badge — Odoo 20

Odoo 20 upgrade of the original Odoo 19 module.

The technical module name remains `inom_pos_stock_badge` so existing installations/configuration references are preserved.

Preserved functionality:
- POS product stock badges with normal/low/out-of-stock states
- Configurable badge position and colors
- On-hand / available stock modes
- Low-stock threshold
- Allow/disallow out-of-stock ordering
- Minimum remaining-stock order restriction
- Low Stock toolbar button
- All-warehouse / current-session-location stock display
- Location-wise stock popup
- 30-second stock synchronization
- Order item count on POS screen and receipt
- Product/order/payment stock validation
- Existing POS configuration fields and settings
