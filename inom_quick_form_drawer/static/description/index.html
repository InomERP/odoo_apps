Quick Record Access

Key Highlights

Quick Form Drawer

Open and edit any record directly from list views using a smooth slide-in drawer without leaving the current page. The drawer loads Odoo’s full native form view, allowing users to edit, save, use smart buttons, trigger actions, and access chatter seamlessly for a faster and more efficient workflow experience.

Works Across All List Views

Automatically adds a quick access eye icon to every row in all Odoo list views without requiring any model-specific configuration. The feature is globally applied through Odoo’s core list renderer, making it instantly available across all modules for a consistent and efficient user experience.

Fully Editable Form View

The drawer uses Odoo’s native form view component, allowing users to perform all standard actions directly inside the panel. Users can edit records, save changes, discard updates, use smart buttons, execute header actions, manage statusbars, and interact with chatter exactly like the default standalone form view.

Smooth Slide-In Experience

Provides a modern and responsive user interface with a right-side slide-in drawer animation and dimmed background overlay. Users can easily close the drawer using the close button, clicking outside the panel, or pressing the ESC key, ensuring a seamless and intuitive navigation experience throughout the application.

One-Click Record Preview

Quickly preview any record directly from the list view using the integrated eye icon. Users can access complete record details instantly without navigating away from the current screen, improving productivity and making record management faster and more convenient.

Interactive Form Access in Drawer

Access complete record details inside a fully interactive side drawer without leaving the current list view. Users can work with order lines, smart buttons, statusbars, chatter activities, and form actions directly within the drawer, providing a smooth and efficient record management experience.
