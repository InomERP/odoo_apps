Odoo Sales Automation | Auto Invoice | Auto Delivery

This module enables Instant Sale Automation in Odoo 19. When a quotation is confirmed as an Instant Sale, the system automatically:

  • Validates the delivery order (if stock is available in the selected source location)
  • Creates and posts the customer invoice
  • On cancellation: auto-creates return delivery and cancels/reverses the invoice

Key Features

  • Instant Sale View Type: Select "Instant Sale" as Sales View Type on quotations
  • Source Location: Choose warehouse source location for stock validation
  • Stock Validation: Prevents confirmation if insufficient stock
  • Auto Validate Delivery: Delivery auto-validated on order confirmation
  • Auto Create Invoice: Invoice auto-created on order confirmation
  • Auto Post Invoice: Invoice auto-posted without manual intervention
  • Auto Return Delivery on Cancel: Return transfer auto-created and validated
  • Auto Cancel Invoice on Cancel: Credit note created and invoice reversed
  • Sequence Prefix: Configurable prefix for Instant Sale order sequences
  • User Rights: Instant Sales User and Manager access groups

Configuration

Go to Sales → Configuration → Settings → Instant Sale Automation to enable/disable each automation option.

Go to Settings → Users → User → Other → Instant Sales to assign Instant Sale Manager rights.
