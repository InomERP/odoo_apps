Access Rights Setup

Grant the "View Product Cost" access right to trusted users from the user's Access Rights tab. Anyone without this right will have the cost field hidden automatically.

Cost Visible (Authorized User)

Authorized users see the full cost price on the product form, exactly as in standard Odoo.

Cost Hidden (Restricted User)

Users without permission cannot see the cost price. The field is hidden, keeping your pricing data secure.

Frequently Asked Questions

Which users can see the product cost after installing?

Only users assigned the "Show Cost Price" access right can view the cost. All other users have the cost field hidden automatically.

Does it hide cost in list views and reports too?

Yes. Cost visibility is enforced on the product template and variant forms, list views, kanban cards, and standard reports.

Is any technical configuration required?

No coding is required. Just install the module and assign the access right from Settings > Users. It works out of the box.
