Library Module Overview

This screen displays the complete Library module menu. From here, users can manage book circulation, maintain the library catalogue, configure library settings, and monitor fines and reservations through a centralized interface.

Book Issues

The Book Issues screen is used to issue books to students or faculty members. It records issue dates, due dates, and borrower information for proper library management.

Issue Book

This form is used to issue a new book to a library member. Users can select the member, choose the book copy, and define the issue and return dates.

Books

The Books screen maintains the complete library catalogue, including book details such as title, author, ISBN, category, and publisher.

Copies

The Copies screen manages individual physical copies of books, allowing the library to track availability and circulation status.

Members

The Members screen contains all registered library members, including students and staff who are authorized to borrow books.

Authors

The Authors screen maintains author records that can be linked with multiple books in the library catalogue.

Publishers

The Publishers screen stores publisher information used while maintaining book records.

Hostel Module Overview

This screen displays the complete Hostel module menu. It allows administrators to manage hostel allotments, hostel infrastructure, student accommodations, room transfers, complaints, visitors, and attendance from a single interface.

Allotments

The Allotments screen manages hostel room allocations for students. It records student details, assigned hostel, room, bed, and current allotment status.

Allot Bed

The Allot Bed screen is used to assign an available bed to a student within a selected hostel room while maintaining occupancy records.

Blocks

The Blocks screen organizes hostels into multiple blocks, making hostel infrastructure easier to manage.

Floors

The Floors screen manages floor information for each hostel block and helps organize rooms efficiently.

Rooms

The Rooms screen maintains room details, including room numbers, associated floors, occupancy, and availability.

Beds

The Beds screen manages individual beds within hostel rooms and tracks their current allocation status.

Complaints

The Complaints screen records maintenance and service requests submitted by hostel residents and helps monitor their resolution status.

Transport Module Overview

This screen displays the complete Transport module menu. It allows administrators to manage transport subscriptions, routes, stops, vehicles, drivers, and student transportation services from a centralized interface.

Subscriptions

The Subscriptions screen manages transport pass subscriptions for students. It records route assignments, boarding stops, transport fees, and subscription status.

New Subscription

The New Subscription form is used to create a new transport subscription by assigning a student to a specific route and boarding stop while defining the applicable transport fee.

Routes

The Routes screen maintains all transport routes operated by the institution, including route names, coverage areas, and assigned stops.

Stops

The Stops screen manages boarding and drop-off locations for each transport route, making route planning and student assignments easier.

Vehicles

The Vehicles screen maintains information about all transport vehicles, including vehicle details, capacity, registration information, and operational status.

LMS Module Overview

This screen displays the complete Learning Management System (LMS) module menu. It enables institutions to manage assignments, study materials, student submissions, academic progress, and online learning activities from a centralized platform.

Assignments

The Assignments screen manages all academic assignments. Faculty members can create assignments, define subjects, set due dates, assign maximum marks, and publish them for students.

Study Materials

The Study Materials screen stores and organizes learning resources such as notes, documents, presentations, and reference materials for different subjects.

Progress

The Progress screen tracks students' academic performance within the LMS by monitoring assignment completion, grades, submissions, and overall learning progress throughout the course.

Certificates Module Overview

This screen displays the complete Certificates module menu. It enables administrators to manage certificate requests, issue certificates, generate certificates in bulk, manage student ID cards, and configure certificate templates from a centralized interface.

Requests

The Requests screen manages certificate requests submitted by students. Administrators can review requests, verify details, and process them for approval or rejection.

Certificates

The Certificates screen maintains all generated certificates. It allows users to view, print, download, and manage issued certificates while maintaining complete records.

Batch Generate

The Batch Generate screen enables administrators to generate multiple certificates simultaneously for selected students, reducing manual effort and improving efficiency.

ID Cards

The ID Cards screen is used to create and manage student identity cards. Users can generate, print, and maintain ID card records with student information.

Templates

The Templates screen manages certificate and ID card templates. Administrators can configure layouts, design elements, and formatting to ensure consistent document generation across the institution.

Campus 360 Module Overview

This screen displays the complete Campus 360 module. It provides a centralized 360-degree view of student information, allowing administrators and faculty to access academic, administrative, financial, and personal records from a single location.

Student 360

The Student 360 screen provides a comprehensive profile of each student by consolidating academic records, admission details, attendance, fee information, examination results, library activity, hostel allocation, transport subscription, certificates, and other institutional data into a single interface. This enables users to quickly access complete student information without navigating through multiple modules.

Configuration Module Overview

This screen displays the complete Configuration module menu. It allows administrators to configure institutional master data such as faculties, schools, departments, and other organizational structures required for the university management system.

Faculties / Schools

The Faculties / Schools screen is used to manage the institution's faculties and schools. Administrators can create, update, and organize different faculties or schools that serve as the top-level academic structure.

Departments

The Departments screen manages academic departments under each faculty or school. It allows administrators to define department details, associate them with the appropriate faculty, and maintain the organizational hierarchy for academic operations.
