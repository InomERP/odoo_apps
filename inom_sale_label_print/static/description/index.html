Key Highlights

Instant Direct Print — No Download Step

Send labels straight to a printer from the wizard — auto-print a PDF in the browser, stream ZPL over a network socket, push through QZ Tray, or route to an IoT Box, with no manual file handling.

One Printer Setup, Used by Everyone

Admins register each printer once — name, transport, host, and port — and users simply pick it from a dropdown, with an optional default printer per user for one-click printing.

Print Labels Without Leaving Your Workflow

Print labels directly from Products, Sale Orders, Purchase Orders, or Pickings — quantities and templates are pre-filled automatically, so no separate trip to a print screen is needed.

Label Builder Access Configuration

Go to Settings → Users → Access Rights to assign the Label Builder role (User, Designer, or Manager) per user, controlling who can print, design, and manage label templates, paper formats, and configuration.

Access Label Builder Settings View

Go to the Apps menu → Label Builder to configure global settings, manage Label Types, Paper Formats, and templates, and control default preview data for the entire module.

Manage Label Templates View

Go to Label Builder → Templates to view, create, duplicate, or archive label designs — each linked to a Label Type and Paper Format, with live counts of labels per page and elements.

Configure Label Types & Paper Formats View

Go to Label Builder → Configuration to manage Label Types (Product, Partner), define Paper Formats with custom grid and page sizes, or import label designs shared as JSON files.

Ready-Made Paper Format Presets View

Go to Label Builder → Configuration → Paper Formats to choose from A4 sheets, Letter address grids, and thermal rolls — or create your own with custom columns, rows, and label dimensions in millimeters.

Precise Page & Label Geometry View

Set page size, grid columns and rows, exact label width and height, margins, and gaps in millimeters — the system auto-validates that everything fits perfectly on the page.

Import Templates via JSON View

Go to Configuration → Import Template, upload a previously exported .label.json file, and instantly restore a complete label design — layout, elements, and styling included.

Build, Preview & Manage Elements View

Add fields, barcodes, and text elements directly in the Elements tab with exact positions and sizes, then use Open Designer, Test Print, Export, or Duplicate to design, verify, and reuse your template.

Visual Drag & Drop Designer View

Add Text, Field, Price, Barcode, QR Code, Image, and Shape elements onto a true-to-size canvas — position, resize, style, and reorder layers, with live sample data and instant test prints.

Instant Test Print Preview View

Click Test Print to instantly generate a real PDF with actual record data — verify names, addresses, and formatting exactly as they'll appear before printing the full batch.

Archive Unused Templates Safely View

Archive outdated or unused label templates with a single confirmation click — archived templates stay in the system for reference but no longer appear in the print wizard.

Full Audit Trail on Every Change View

Every action — archiving, activating, or editing a template — is automatically logged in the chatter with timestamp and user, giving you complete traceability for compliance and troubleshooting.

Print Directly from Any List View View

Select one or more products, click Actions → Print Labels (INOM), and instantly open the print wizard — no need to open individual records or switch apps.

Smart Template Search & Selection View

Instantly search and pick from all available label templates in the print wizard — showing labels per page and element count at a glance, with archived designs automatically excluded.

Powerful Print Wizard — Full Control View

Adjust quantities per line, merge duplicates, skip already-used labels, and choose PDF or ZPL thermal output — all from one wizard before printing, with per-line include toggles for full control.

Print Labels Directly from a Sales Order View

Open any Quotation or Sales Order and click Print Labels in the header to generate labels for every product in the Order Lines, without leaving the order. The same Download or Direct Print options are available, so labels can be sent straight to a saved printer from the sale flow itself.

Review Quantities Before Printing View

The wizard auto-fills one label line per order product, using the sale order quantity — 10 for Acoustic Bloc Screens, 20 for Cabinet with Doors, totaling 30 labels here. Adjust quantities, toggle lines on or off, or add extra lines before choosing Print Mode and Output and clicking Print.

Multi-Page Label Sheet Output View

When the total label count exceeds one page, the generated PDF automatically flows onto additional pages — here, all 30 labels for Acoustic Bloc Screens and Cabinet with Doors are laid out across 2 pages, ready to print on a standard label sheet.

Direct Print from a Sales Order View

On a Sales Order, switch Print Mode to Direct Print and pick a saved Printer to send all 30 labels straight to it — no PDF download step, whether printing from a quotation or a confirmed order.

For printing images in the report first we have enable 'Show Product image in the report' option in the configuration settings.
